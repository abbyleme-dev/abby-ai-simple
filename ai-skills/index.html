大專校院｜教師增能研習

教師 AI Skills 應用研習：減輕備課、行政與專題指導負擔

以教師備課、行政與專題指導需求為主軸，介紹 Skills、AI Agent 與 Gemini Notebook 之教學應用。

對象
大專校院教師與教職員
建議時數
2 場 × 3 小時，共 6 小時
可擴充為 3 場，加強實作與回饋
建議形式
線上為主
課程目的 預期成效 課程大綱 需求設備 講師簡介 近期合作學校
Purpose

課程目的

以教師備課、行政與專題指導需求為出發點，帶領教師運用 ChatGPT 與 Gemini，將重複性工作整理為 Skill，並認識 AI Agent 的應用；同時介紹運用 Gemini Notebook 輔助學生專題的資料整理、查證與成果呈現方法。

了解如何建置 Skill

將固定工作步驟，建置為可重複使用的指令，減低備課與行政的重複性工作。

了解 AI Agent 的基礎設定

完成基本設定，由 AI Agent 依指令，自動執行會議紀錄、通知撰寫等行政任務。

運用 Gemini Notebook 指導專題

整合多元資料並回溯原始出處，引導學生查證資料，並將專題資料轉為學習指南、心智圖與簡報。

Outcomes

預期成效

完成兩場研習後，學員預期能：

  1. 建立備課 Skill，減低重複性工作依授課單元產出教學目標、課程流程與提問設計，毋須每次重新撰寫指令。
  2. 了解 AI Agent 之運作方式與基本設定掌握 AI Agent 可協助的工作範圍與設定方式，以及須由教師判斷的環節。
  3. 運用 Gemini Notebook 指導學生專題研究熟悉 Gemini Notebook 的操作，引導學生進行資料查證、研究問題聚焦與專題成果整理。
Sessions

課程大綱

本研習分為兩場，每場 3 小時，以講師示範為主，並安排實作練習。

可擴充為三場如主辦單位希望加強實作，可增加第三場（3 小時）實作與成果分享：教師依所屬課程，完成個人備課 Skill 與專題指導範本，講師逐一提供修正回饋，並進行成果交流。

教師 AI Skills 入門：從 Skill 建置到 AI Agent 設定

適用對象：有意提升備課與行政效率之教師
第 1 小時講授

從提示詞到 Skills：概念與操作入門

說明提示詞、Skills 與 AI Agent 的差異及教學應用情境，介紹 ChatGPT、Gemini 桌面版的操作介面與帳號使用注意事項，並示範以任務拆解方式撰寫指令。

預期產出：依任務拆解原則撰寫之指令範例
第 2 小時實作

備課 Skill 實作

以授課單元為例，將教學目標、課程流程與提問設計整理為 Skill，並於不同 AI 工具間應用。

預期產出：個人授課科目之備課 Skill
第 3 小時示範

行政流程 Skill 與 AI Agent 設定

示範將會議紀錄整理、通知信撰寫等行政流程建立為 Skill，並說明 AI Agent 的運作方式與基本設定；同時徵集教師的工作需求，作為下一場的示範素材。

預期產出：AI Agent 設定步驟講義；彙整教師工作需求

教師 AI Skills × Gemini Notebook 應用：AI 輔助學生專題指導

適用對象：指導學生專題、實務專題或畢業製作之教師
第 1 小時示範

AI 輔助專題研究與資料查證

分享前一場教師需求的 Skill 成果；說明專題各階段 AI 可協助之處，示範運用 Gemini Notebook 整理多元資料並回溯原始出處，建立查證觀念。

預期產出：學生資料查證步驟清單
第 2 小時實作

專題指導提示詞與 Skill 應用

將選題比較、研究問題聚焦、問卷設計等指導步驟，整理為提示詞範本或 Skill，引導學生依步驟思考與產出。

預期產出：依所屬系科調整之專題指導範本
第 3 小時示範

Gemini Notebook 延伸應用

示範將整理好的專題資料轉為學習指南、心智圖、簡報等形式，協助學生理解資料並準備發表。

預期產出：學習指南、心智圖與簡報成品範例
